# DOCUMENTATION RULES

Every project must document:

- Purpose
- Architecture
- Installation
- Environment variables
- Local development
- Testing
- Deployment

## Architecture Changes

When architecture changes, update:

docs/architecture.md

## Important Decisions

Document significant architectural decisions in:

docs/decisions/

Use:

Context
Decision
Alternatives
Consequences

## README

README should allow a new developer to:

1. Understand the project.
2. Install it.
3. Configure it.
4. Run it.
5. Test it.
